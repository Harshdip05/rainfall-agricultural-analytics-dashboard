# Dataset

This folder contains the dataset used for the
Rainfall & Agricultural Analytics project.

## Dataset Information

- File: data_season.csv
- Records: 3,158
- Columns: 12
- Time Period: 2004–2019

## Main Attributes

- Year
- Location
- Area
- Rainfall
- Temperature
- Soil Type
- Irrigation
- Yield
- Humidity
- Crops
- Price
- Season

The dataset is used as the raw input for the AWS S3 →
Snowflake → SQL → Power BI analytics pipeline.
